# CoffeeCup App Frontend

Welcome to CoffeeCup App Frontend!

## Installation

To start the CoffeeCup app on your device, follow these steps:

1. Make sure you have Node.js and npm installed.
2. Clone the repository from GitHub:
 
 ```bash
git clone https://github.com/yourusername/CoffeeCup.git
```

3. Navigate to the project directory:

```bash
cd CoffeeCup
```

4. Install the dependencies:

```bash
npm install
```

5. Start the app:

```bash
npx expo start
```

6. Download and open the "Expo" app on your phone and scan the QR code displayed on your terminal.
